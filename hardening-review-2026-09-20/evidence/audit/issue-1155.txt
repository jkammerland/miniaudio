Title: Security: Heap Use-After-Free (CWE-416) in extras/decoders/libopus/miniaudio_libopus.c

## Summary
A heap use-after-free vulnerability exists in the optional libopus decoding backend of miniaudio.
When processing specially crafted Opus audio input, a race condition can trigger invalid memory access.
Impact: Application crash (denial of service), possible memory corruption on vulnerable builds.

Affected version: [INSERT YOUR TESTED VERSION]
Component: extras/decoders/libopus/miniaudio_libopus.c

## Reproduction
Environment: Ubuntu 22.04, clang-14, AddressSanitizer
